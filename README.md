# FORMA

**Create in 3D. Bring it to life.**

FORMA is a browser-based creative tool for designing, customizing, animating, and exporting interactive 3D shapes.

Built to make 3D creation more accessible, FORMA brings together shape generation, realistic materials, visual customization, and interaction in a single web-based experience.

## Overview

FORMA explores a simpler approach to creating interactive 3D visuals for digital products and experiences.

Users can experiment with shapes, apply materials, customize their appearance, and bring their creations to life through animation and interaction.

No traditional 3D modeling workflow is required.

## Key Features

- **3D Shape Creation** — Create and explore three-dimensional forms directly in the browser.
- **Materials & Appearance** — Customize surfaces with different materials, colors, and visual effects.
- **Animation** — Bring static shapes to life with motion.
- **Interaction** — Create visuals that respond to user input.
- **Image, Text & Drawing** — Explore different creative inputs for generating and personalizing shapes.
- **Export** — Export visual assets or integrate interactive 3D creations into digital experiences.
- **Browser-Based** — Create directly on the web without installing software.

## Design Philosophy

FORMA is built around the idea that creative tools should encourage experimentation rather than impose complexity.

Its goal is to make interactive 3D design feel immediate, expressive, and approachable, bridging the gap between visual design and implementation.
